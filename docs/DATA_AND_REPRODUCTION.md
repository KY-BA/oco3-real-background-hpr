# Data and reproduction routes

## What is included

- `results/reference/seed_predictions.csv`: 495 saved predictions (three models x five seeds x 33 scenes). Column names and plant identifiers are normalized, while prediction numeric strings are preserved from the formal exports. Local drive paths are omitted.
- `manifests/evaluation_scenes.csv`: the 33 included plant/scene pairs, coordinates, sizes, and hashes.
- `manifests/evaluation_selection_all_40.csv`: the full original 40-row selection record, including seven excluded rows. Eight embedded U+FEFF characters in original filenames were removed; scene names and inclusion decisions were not changed. Directory locations were made portable.
- `data/backgrounds/`: 13 byte-identical gridded-background NPZs. Their diagnostic JSON retains the original values and replaces the original local input path with its source filename.
- `manifests/backgrounds_13.csv`: A/B groups, environmental categories, 9/2/1/1 scene-level partitions, and four screening diagnostics. The extraction script diagnoses background-likeness; the released manifest records the actual final curation. It is not an automatic A/B classifier.
- `manifests/mixed_fill_values.json`: exact float32 medians of XCO2, u, v from the training subset, with the source H5 hash. No evaluation scenes were used to estimate them.
- The separate reproduction-assets archive contains 15 best checkpoints, their normalization/configuration files and available training logs, plus the 33 retained observational NC4 files. Source providers' attribution and access terms remain applicable; no new blanket license is assigned to third-party data by this package.

## Original data sources

The upstream repository directs users to [Zenodo 10.5281/zenodo.12788520](https://doi.org/10.5281/zenodo.12788520) for the data and pretrained models associated with the upstream work. The paper and software provenance are recorded in `manifests/upstream.json`. OCO-3 background metadata records the exact daily Lite filenames, UTC windows, spatial bounds, and diagnostic values. Retained evaluation files are identified individually by name and SHA-256, rather than claiming that any current download will necessarily be the same version.

The multi-gigabyte SMARTCARB and mixed training datasets are not duplicated in the GitHub code archive. The original SMARTCARB file used here is `2km_forOco3_32/dataset.nc`. It contains `plume`, `emiss`, `idx_img`, `point_source`, `u`, and `v`. Both construction commands below use this **same NetCDF4/HDF5 file**.

## Construct the mixed dataset

From the repository root, substitute actual paths for `/path/to/...`:

```bash
python tools/build_earth_balanced_v2_plus_alpha_absolute_h5.py --a-dir data/backgrounds/A_class --b-dir data/backgrounds/B_class --plume-dataset /path/to/2km_forOco3_32/dataset.nc --source-manifest manifests/backgrounds_13.csv --out-dir /path/to/new_mixed_absolute --seed 42
python tools/add_uv_channels_to_mixed_h5.py --src-dir /path/to/new_mixed_absolute --out-dir /path/to/new_mixed_xco2uv --plume-dataset /path/to/2km_forOco3_32/dataset.nc
```

Use new output directories: these original data builders write output files and do not implement the training launcher's overwrite protection. The first constructs balanced mixed XCO2 fields and training-only plus-alpha samples; the second appends the paired simulated u/v fields by `source_idx_img`. Simulated emissions remain the labels. Validation backgrounds are not used for training and validation samples are not augmented.

The background arrays already included here allow these steps without re-extracting the satellite backgrounds. To redo extraction, `tools/extract_sam_scene_from_daily_lite.py --help` lists the input filename/window/bounding-box options; obtain the exact source products named in the corresponding metadata. Historical final curation is represented by the fixed manifest, not by inventing an additional screening rule.

## Reproduction coverage

The standard-library metric checker covers the numerical CNN comparison, CNN/HPR comparison, emission-group summaries, seed variability, and the appendix's fixed plant-level gate. These predictions also support the numerical content of Figures 5, 6, 7, and 9.

Exact final intermediate arrays used for Figure 8 were not identified during packaging. Older diagnostics with different HPR checkpoints were deliberately not presented as its reproduction data. Schematic figures and manuscript page layout are not regenerated by this code package. Full training and full dataset construction were not rerun as part of this preparation.
